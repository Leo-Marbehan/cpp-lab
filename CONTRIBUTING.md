# Contributing

This is a personal learning repository, public so that others can read it.

- **Issues are welcome**: bugs, questions about how something works, suggestions. Use one of the
  issue templates.
- **Pull requests are not accepted.** The point of the repository is to write the code myself; pull
  requests from others will be closed without review, however good they are. If you have an
  improvement in mind, open an issue describing it instead.
- **Security problems**: please don't open a public issue; see [SECURITY.md](SECURITY.md).

Feel free to fork and reuse the code under the [MIT license](LICENSE).
